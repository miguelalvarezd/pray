# Pray (Flutter app)

This is the app. For what it does, how to run it on a phone and how to run the tests, see the [repository README](../README.md).

Quick start:

```bash
flutter pub get
flutter run
flutter test
```

The liturgical data in `assets/liturgy/liturgy.json` is generated by [`tools/liturgy`](../tools/liturgy/README.md); don't edit it by hand. Store listing drafts are in [STORE_METADATA.md](STORE_METADATA.md).
