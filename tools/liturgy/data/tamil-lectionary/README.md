# Tamil Catholic Lectionary (seed data)

Copied from [jayarathina/Tamil-Catholic-Lectionary](https://github.com/jayarathina/Tamil-Catholic-Lectionary) (`MySQL/`, April 2024), released into the public domain under the Unlicense (see `LICENSE`).

Only the reading **references** are used: `readings__list.sql` (day id, reading slot, reference) and `generalcalendar.sql` (the saints' dates and codes). Book names are Tamil abbreviations; the generator maps them to neutral book ids. Psalms use Hebrew numbering.
